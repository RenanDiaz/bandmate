🎼 Bandmate

Bandmate is a modern web application designed for musicians, bands, and collaborators to:
- Manage a shared songbook (lyrics, chords, tempo, key, tags, etc.)
- Build and organize setlists for rehearsals and gigs
- Schedule and document gigs with linked setlists
- Collaborate with band members and temporary guest musicians
- Export printable or sharable songbooks and setlists

Built with React + TypeScript and powered by Supabase.
