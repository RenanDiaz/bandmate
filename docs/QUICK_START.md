# Quick Start - Band Member Management

## 🚀 Apply Migration NOW

1. Open: https://supabase.com/dashboard
2. Go to: **SQL Editor** → **+ New query**
3. Copy/paste: Contents of `BAND_MEMBERS_MIGRATION_V3.sql`
4. Click: **Run**
5. See: "Migration completed successfully!"

## ✅ Test Features

1. Go to: http://localhost:5173
2. Login to your account
3. Click: **People icon** next to any band
4. Test: Invite member, view members, change roles
